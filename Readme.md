# Sabor Express

Aplicação em Python para cadastro e gestão simples de restaurantes, desenvolvida como projeto final do curso **"Python: crie a sua primeira aplicação"** (Alura).

## Funcionalidades

- **Cadastrar restaurante**: registra nome e categoria em um dicionário, armazenado em uma lista.
- **Listar restaurantes**: exibe todos os restaurantes cadastrados.
- **Alternar estado do restaurante**: ativa ou desativa um restaurante já cadastrado (buscado pelo nome).
- **Finalizar o programa**.

## Conceitos aplicados

- Manipulação de strings
- Módulos e funções
- Listas, laços e exceções
- Dicionários

## Como executar

```bash
python app.py
```
